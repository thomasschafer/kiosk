     Trade-offs
     - Extra memory usage (O(n)) for arrays.

     Bottom-up (iterative) variant
     - Instead of recursion, merge subarrays of size 1, then 2, then 4, then 8, etc.
     - Same asymptotic complexity: O(n log n) time, O(n) extra space.
